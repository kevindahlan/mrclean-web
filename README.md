# Mr Clean Laundry Website

Landing page promosi Mr Clean Laundry dengan desain modern-premium, responsif untuk ponsel dan desktop, dan tanpa proses build.

## Isi
- `index.html` — website utama.
- `.github/workflows/pages.yml` — workflow untuk deployment ke GitHub Pages saat ada push ke `main`.

## Publikasikan dengan GitHub Pages
1. Buka **Settings** repository.
2. Pilih **Pages** pada menu samping.
3. Di bagian **Build and deployment**, pilih **GitHub Actions** sebagai source.
4. Buka tab **Actions** dan tunggu workflow **Deploy Mr Clean website to GitHub Pages** selesai.
5. URL situs akan terlihat pada Settings → Pages atau di hasil deployment workflow.

Repository: https://github.com/kevindahlan/mrclean-web
